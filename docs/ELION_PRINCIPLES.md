# ELION Principles

ELION is guided by a clear product and engineering constitution.

1. Humanity first
2. Peaceful technology
3. Scientific honesty
4. Engineering rigor
5. Security by design
6. Accessibility for everyone
7. Global participation
8. Transparency where appropriate
9. Privacy and responsible data handling
10. No fake claims
11. Performance matters
12. Technology should serve people

Additional principle:

Never sacrifice real engineering quality for visual spectacle.

This principle is especially important for the public website and all technical work. ELION must remain credible, performant, and honest. The project should not trade substance for style, nor promise capabilities it cannot deliver.

ELION values practical utility, careful design, and trust. The mission is not only to build impressive systems, but to create technology that genuinely helps people and supports a peaceful future.
